# Bank Operations Widget

Виджет для маскировки и обработки банковских операций клиента.

## Возможности

- Маскировка номеров карт (формат `xxxx xx** **** xxxx`)
- Маскировка номеров счетов (формат `**xxxx`)
- Преобразование даты из ISO-формата в `ДД.ММ.ГГГГ`
- Фильтрация списка операций по статусу (`EXECUTED`, `CANCELED` и др.)
- Сортировка списка операций по дате (по возрастанию или убыванию)
